# Amigo Secreto

**Amigo Secreto** é uma aplicação simples e intuitiva para realizar sorteios de amigo secreto de forma dinâmica. Com essa ferramenta, você pode adicionar os nomes de seus amigos, visualizar a lista de amigos e realizar o sorteio de forma rápida e eficiente.

## Funcionalidades

1. **Adicionar amigos**: O usuário pode inserir o nome de um amigo no campo de entrada e adicionar à lista.
2. **Visualizar lista de amigos**: A lista de amigos será exibida abaixo conforme forem adicionados.
3. **Sortear amigo secreto**: O sistema sorteia aleatoriamente um nome da lista de amigos e exibe o nome do sorteado.

## Tecnologias Usadas

- **HTML**
- **CSS**
- **JavaScript**
- **Vercel**

## Como Funciona

1. **Adicionar amigo**: O usuário digita o nome de um amigo no campo de entrada e clica no botão "Adicionar". O nome será adicionado à lista de amigos.
   
2. **Visualização da lista**: Cada vez que um amigo é adicionado, a lista de amigos na tela é atualizada dinamicamente.
   
3. **Sorteio**: Quando o botão "Sortear amigo" é pressionado, a função de sorteio escolhe aleatoriamente um nome da lista de amigos e exibe o nome sorteado na tela.
